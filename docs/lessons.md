# 今回わかったこと（TZ 230 GHz ファーストライト）

TZ 受信機の 230 GHz モード（DSB）のファーストライトで、nobs の H40 の指示書を変換して観測させた。
そのときにわかった、**ほかの受信機や今後のプロジェクトでも使える知見**をまとめる。
個々の決定の経緯は [`policy.md`](policy.md)、欄の一覧と式は [`fields.md`](fields.md)。

> 2026-11-09 時点。変換した指示書が実機で動いた。

## 1. 観測所の環境

- **観測所の計算機（ut12x1）の `python` は Python 2.7.12（Anaconda）**。スクリプトは Python 2 と 3 の両方で動くように書く。
  - ファイルに日本語（ASCII 以外）があると、2 行目までに `# -*- coding: utf-8 -*-` がなければ `SyntaxError: Non-ASCII character` で止まる。
  - `argparse` や `open(newline=…)`、`os.makedirs(exist_ok=…)`、f-string は使わない（2.6 も考えるなら `optparse`）。
  - `json` は Python 2 では `unicode` を返す。日本語のメッセージ（バイト列）と混ぜると落ちるので、`str` にそろえる。
  - `round()` は 2 と 3 で丸め方が違う。値をそろえたいときは `floor(x + 0.5)` を使う。
- 指示書は `/cosmos3/45m/obstable/<ユーザー>/<プロジェクト>/` に置かれる。COSMOS はここから読む。
- 実機では、スクリプトをコピーして使うことがある（`~/python` など）。**スクリプトと設定ファイルの版がずれやすい**ので、
  設定の項目が足りないときは、何が足りないかを示して止めるようにした。リポジトリごと clone して `git pull` で更新するのが安全。
- 手元（ビルドサーバ）には Python 2 がなく、Docker も使えなかった。Python 2 での確認は実機でしかできない。

## 2. nobs が出す指示書

- **同じ名前で拡張子だけ違うファイルの組**で出る。ファイル名をそろえる必要があるので、変換後も同じ名前にする。
  元のファイルは nobs ですぐ作り直せるので、その場で上書きしてよい（二重に変換しないよう、変換済みなら止める）。
- 指示書には観測者 ID が入る（`% OBSERVER`、`SET SAM45 OBS_USER`、`GROUP` など）。公開リポジトリに置くときは伏せる。
- **手元のサンプルと、実機で観測者が作ったものは形が違うことがある**。
  例: サンプルの `.dat` は全行に 2nd LO があったが、実機のものには `01,#     ,,` のような行があった。

### `.start`

- 1 行 1 命令。`%` で始まる行と `#` で始まる行はコメントで、COSMOS は読まない。
- 冒頭に MLPPS で受信機ごとの LO スイッチを切り替える命令がある（H40 なら `losw_h40.py`）。
- SG（シンセサイザ）は `SYNTHE_x` という名前で、`SET SAM45 REF_NUM` で Array ごとに番号で参照される。

  | SG | `REF_NUM` | 使った受信機 |
  |---|---|---|
  | `SYNTHE_K` | 11 | H40 |
  | `SYNTHE_N` | 14 | TZ 230 GHz（`RX_NAME 'TZ230DSB'`） |

  ヘッダの `% OBS_FREQn`・`% FREQ_IFn`・`% FEn` の n も同じ番号（H40 は n = 11）。
- `SET SAM45` のカンマ区切りのリストは、**要素の数で意味が決まる**。
  - 32 個: Array ごと（A01〜A32）。`REST_FREQ`・`OBS_FREQ`・`FREQ_IF1`・`RX_NAME`・`SIDBD_TYP`・`ARRAY`・`IFATT`・`REF_NUM`・`FQDAT_F0` など。
  - 64 個: Array ごとに 2 つ。`FQDAT_FQ`（ch 4096 と ch 1 の RF）・`FQDAT_CH`（4096, 1）・`CH_RANGE`。
  - 2 個: SpW・サブアレイごと（`START_CHAN_SUB1`・`INPUT_MODE` など）と `SRC_POS`。
  - 使わない Array は、文字列なら空、小数なら `0.0`、整数なら `0` にしておけばよい。
- 数値の書式は Java の `Double.toString` と同じ（`4.3E10`、`6.0E9`、`2.30538E11`）。
- SAM45 の `START_CHAN` は 16 か 64 の倍数のはず（念のため 64 の倍数にした）。

### `.dat`（SAM45 の前の共通 IF 系）

- `Array 番号,スイッチ（受信機名、6 文字）,サイドバンド,2nd LO（MHz、小数 3 桁）` の 16 行。`SET RXT SETUP_FILE` で参照される。
- **スイッチは、受信機名とサイドバンドの組み合わせで制御している**。周波数の計算には使わない。
  TZ の 230 GHz を TZ2V のポートに入れたときも、サイドバンドの欄は USB の線の Array でも `LSB` のままにした。
- **使わない行にも 2nd LO が要る**（空だと動かなかった）。使う Array と同じ値を入れておけばよい。
- 使わない行は `05,#     ,,`（カンマ 3 つ、周波数なし）。

## 3. 周波数の系

```
RF --1st LO--> 1st IF --2nd LO（.dat）--> 2nd IF 2–4 GHz --> SAM45（第 2 ナイキスト、524,288 点）
```

- 1st LO = `OBS_FREQ − FREQ_IF1`（USB）を、実行時に SG がドップラー補正する。**指示書には 1st LO は書かれない**ので、
  変換するときにドップラー補正を計算する必要はない。
- 2nd LO は 1st IF の上にあり、**2nd IF では周波数が反転する**。nobs は線を 2nd IF の 3 GHz（窓の中央）に置く:
  `2nd LO = 1st IF(線) + 3 GHz`。
- `FQDAT_FQ` はドップラー補正を入れない静止系の RF で、10 kHz に丸めてある。式は [`fields.md`](fields.md)。
  **nobs が出した H40 の値（`FQDAT_FQ`・2nd LO）を式から 1 文字も違わずに再現できた**ので、式は信頼してよい。
- 共通 IF 系は 1st IF 4–8 GHz を 2nd IF 2–4 GHz に落とす。2nd LO は 8–10 GHz と聞いていたが、
  **10.6 GHz（10604.050 MHz）を書いた指示書でも動いた**。12 GHz くらいまで大丈夫かもしれない（未確認）。
  2nd LO を 1 kHz 単位で書いた指示書は受け付けられた。実際の LO の分解能は未確認。
- DSB で USB と LSB の線を同時に見るとき、SG は片方（`SYNTHE` の `OBS_FREQ` の線）にしかドップラー追尾できない。
  もう片方は 1st LO の 2 倍 × v/c ほどずれる（230 GHz 帯で v = 30 km/s なら約 1.5 MHz）。

## 4. TZ 230 GHz モードの設定（ファーストライト時）

| 項目 | 値 |
|---|---|
| LO 系 | SG → 18 逓倍 → ミキサ。設定は指示書の外で行う |
| 1st LO | 223.2 GHz（DSB） |
| IF の取り出し | 既存の **TZ2V** のポート → SAM45 の **A11・A12** |
| 線 | A11 = USB CO(2–1) 230.538 GHz、A12 = LSB SiO v=1 (5–4) 215.59595 GHz |
| 2nd LO | A11 10338.000 MHz、A12 10604.050 MHz（使わない行は A11 と同じ） |
| SG | `SYNTHE_N`（`REF_NUM` 14）、`RX_NAME 'TZ230DSB'` |
| ポインティング | `SET ANT POINTING 'TZ2'` |
| SAM45 `RX_NAME` | `TZ2V` |
| 冒頭の MLPPS（LO スイッチ） | 使わない（コメントアウト） |

## 5. 進め方の教訓

- **装置まわりの事実は、最初に一覧にして確かめる**。今回あとから変わったのは次のもので、どれも装置側の事実だった。
  次に別の受信機・モードで同じことをするときは、最初にこの一覧を確かめる。
  - IF をどのポートから取り、SAM45 のどの Array に入るか（TZ2H・A15・A16 → TZ2V・A11・A12）
  - SG の名前と `REF_NUM` の番号
  - `.dat` に必要なもの（使わない行の 2nd LO、`#` の行のカンマの数、スイッチ欄とサイドバンドの組み合わせ）
  - 2nd LO の設定できる範囲と、線を 2nd IF のどこに置くか
  - 実機の `python` の版
- **形がはっきりしているもの（`.start`）は厳しく、装置の都合で形が揺れるもの（`.dat`）は設定から作り直す**。
  `.start` は知らない形の行があれば止める。`.dat` は入力の中身を使わず、決まった書式で書き出す。
- **使う Array の `.dat` のスイッチ欄と `SAM45 RX_NAME` が食い違ったら止める**チェックを入れた。取り違えを変換時に気づける。
- nobs の出力を式で再現するテストを持っておくと、式を変えたときにすぐ気づける。
