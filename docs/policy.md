# 変換スクリプトの方針

TZ 受信機の 230 GHz モードのファーストライトを、**観測指示書の手作業に近い変換だけで**行うための方針。
nobs・COSMOS マネージャー・LC には手を入れない。

> 出典: 西村さんとの打ち合わせ（2026-11-08〜09）。

## 前提

- TZ 受信機は 86 GHz で運用できている。230 GHz モードでも装置の大半を流用し、新しい LC やマネージャーの修正は要らない。
- 観測者は nobs で **86 GHz 用の指示書**を作る。変換スクリプトがそれを 230 GHz 用に書き換える。
- 観測の流れ（指示書 → マネージャー → LC → ロギング → マージ）は
  [YATSUGATAKE-NRO45-sam45compat の observation-flow.md](https://github.com/nobeyama-radio-observatory/YATSUGATAKE-NRO45-sam45compat/blob/main/docs/cosmos/observation-flow.md) を参照。

## nobs が出すファイル

nobs は**同じファイル名で拡張子だけ違う**複数のファイルを出す。ファイル名は揃っている必要がある。

| 拡張子 | 中身 | 変換 |
|---|---|---|
| `.start` | メインの指示書。SG の設定（`SYNTHE_n`）、SAM45 の設定など | 編集する |
| `.dat` | SAM45 直前の共通 IF 系の設定。スイッチの設定と 2nd LO 周波数（MHz） | 編集する |

書き換える欄の一覧と欄どうしの関係は [`fields.md`](fields.md)。
| その他 | （未確認） | 変えない |

## 周波数の系

```
RF (OBS_FREQ) --1st LO--> 1st IF (FREQ_IF1) --2nd LO (.dat, MHz)--> 2nd IF 2–4 GHz --> SAM45
```

- `.start` の `SYNTHE_n` に `OBS_FREQ`（観測する RF）と `FREQ_IF1`（1st IF の何 GHz に落とすか）が書かれる。
- 1st LO は `OBS_FREQ - FREQ_IF1` に観測者のドップラー速度を補正した値。**`.start` には 1st LO は書かれない**（実行時に決まる）。
  したがって変換スクリプトはドップラー補正を計算しない。
- 230 GHz の LO 系は SG → 18 逓倍 → ミキサ。この設定は別のファイルで行うので、`.start` には書かない。

## 変換の範囲

### 変えるもの

1. `.start` の `SYNTHE_n` の `OBS_FREQ`・`FREQ_IF1`
2. `.start` の SAM45 設定のうち **RF 周波数ラベル**
3. `.dat` の共通 IF 系のスイッチ設定と 2nd LO 周波数

### 変えないもの

- マップ・OTF のグリッドやスキャン間隔
- ポインティングの設定
- 上に挙げたもの以外のすべての行（1 文字も変えない）

## スクリプトの作り

1. **出力は元と同じファイル名**。元のファイルを上書きしないよう、別のディレクトリに書き出す。
2. 書き換えるのは決めた行・欄だけ。変換のたびに、書き換えた箇所の差分（変更前と変更後）を出す。
3. **知らない形の行が出たら止まる**。周波数に関係しそうなのに解釈できない行は、黙って通さずにエラーにする。
4. 230 GHz 側の値（観測する RF など）は、指示書の外の設定ファイルで与える。スクリプトに直書きしない。
5. 変換後に、86 GHz 帯の数値が残っていないかを確認する。ロギング・マージ・QL は指示書の値をそのまま使うので、残っているとデータの見かけが合わなくなる。
6. Python の標準ライブラリだけで書き、観測所の計算機でそのまま動くようにする。

## 決まったこと（2026-11-09）

- TZ 86 GHz 単独の指示書はないので、**H40 の指示書を元に**変換する。
- 230 GHz モードは **DSB**。IF は既存の TZ2H のポートを流用し、SAM45 の **A15・A16** に入る。
- 1st LO は 223.2 GHz。A15 を USB で CO(2–1)（230.538 GHz）、A16 を LSB で SiO v=1 (5–4)（215.59595 GHz）にする。
  1st IF は CO 7.338 GHz、SiO 7.604 GHz。
- 共通 IF 系は 1st IF 4–8 GHz を 2nd IF 2–4 GHz に落とす。2nd LO は 8–10 GHz の範囲で設定できる。
  1st IF 6–8 GHz を通すよう、A15・A16 の 2nd LO は **10000 MHz**。線は 2nd IF で CO 2.662 GHz、SiO 2.396 GHz に来る。
- そのため **SAM45 の窓は変えてよい**ことにした（2026-11-09）。A15 と A16 は同じ窓を使うので、両方の線が入る
  2nd IF 2.25–2.75 GHz（`START_CHAN` 65536〜`END_CHAN` 196607、`CHAN_AVG` 32、500 MHz、122 kHz/ch）にする。
- `SYNTHE_N` は CO を基準にする（`OBS_FREQ` 230.538 GHz、`FREQ_IF1` 7.338 GHz、USB）。DSB なので LSB の SiO は
  ドップラー追尾が少しずれる（v = 30 km/s で約 1.5 MHz）が、ファーストライトでは許容する。
- A01〜A14 の SAM45 の設定（周波数ラベル・有効フラグなど）は H40 の値のまま残す。`QL_RMSARY` は `A15`。
- `.dat` は受信機名とサイドバンドの組み合わせでスイッチを制御しており、周波数の計算には使わない。
  A15・A16 も `TZ2H,LSB`。A15・A16 以外の 2nd LO は元の値を残す。`#` の行は周波数を書かず `05,#     ,` とする。
- SAM45 の `START_CHAN` は 16 か 64 の倍数のはずなので、念のため 64 の倍数に限る（65536 = 64 × 1024）。
- `.start` の書き換え:
  - SG は 1 つだけ使う。`SYNTHE_K` を **`SYNTHE_N`** にし、`SET SYNTHE_N RX_NAME 'TZ230DSB'`。
  - `SET ANT POINTING 'TZ2'`。
  - `SET SAM45 RX_NAME` は `TZ2H`。
  - 冒頭の MLPPS（LO スイッチの切り替え）は `#` でコメントアウトする。
  - `%` で始まる行はコメントなので変えない。
- `.dat` は周波数以外を決まった形（A15・A16 は `TZ2H`）にする。
- サンプルの観測者 ID は伏せる（公開リポジトリのため）。
